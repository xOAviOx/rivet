# Product

## Register

product

## Users

Developers working in their own terminal and repository, using their own model provider account. They need visible, controllable code changes and continuity after interruptions.

## Product Purpose

Inspect a project, perform a coding task, approve consequential operations, verify changes, and resume the saved conversation locally.

## Brand Personality

Calm, precise, dependable. References: Claude Code, Codex, OpenCode for capability and workflow, with an original restrained terminal interface.

## Anti-references

Decorative dashboards, repeated banners, fake metrics, manufactured reasoning, noise, claims without execution evidence.

## Design Principles

Show actual actions. Keep approval scope explicit. Preserve developer work. Make recovery understandable. Keep the primary input stable.

## Accessibility & Inclusion

Keyboard operation, narrow terminals, no-color readability, no status conveyed by color alone, no required animation.
